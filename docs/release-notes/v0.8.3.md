ADF Studio 0.8.3 lets an agent ask several questions in one form. You can
choose from suggested answers, write your own answer, or skip a question.
It also fixes links to agent websites hosted on another computer so they
use that computer's address.

The website-link fix keeps the existing port and protocol; your computer
still needs network access to the remote website using the server's existing
access settings. The npm CLI package for this release declares Node.js
`>=22`; the narrower range documented for current main applies to a future
build, not retroactively to v0.8.3.
