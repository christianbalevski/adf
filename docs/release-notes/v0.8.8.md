ADF Studio 0.8.8 lets you add the same MCP server more than once, each with
its own account: a personal and a work Gmail, for example. Each copy has a
name (`gmail`, `gmail-work`), and agents attach the one they need by name.

## Action needed

MCP sign-ins and keys are now stored by server name, so ones saved by an
earlier version are not found:

- Gmail: sign in again in Settings → MCP Servers.
- Google Drive and Google Calendar: choose the client file again in Settings.
- Remote servers that show as signed out: sign in again.
- Keys entered per agent in the credential panel: enter them again.
- An agent's own Gmail or Google server: have the agent run `mcp_install`
  with `auth: true`.
