Appearance

Theme
Choose a light, dark, or operating-system appearance.
Agent avatars
Show each agent as its orbital or as its emoji in lists, the title bar and the Mesh view.
Chat width
How wide the loop thread runs when the chat is in the center stage. Comfortable caps it at a reading column; Full uses the whole stage.
Only applies when the chat is in the center. In the side dock the panel is already narrow.
Font family
Typeface for the whole interface. System and Inter Tight always work; other presets fall back to the system font if the face isn't installed.
UI scale
Scale the entire interface. Ctrl+= / Ctrl+- still zoom on top of this.
